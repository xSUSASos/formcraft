# Идеи вне MVP

Сюда попадает то, что всплыло по ходу работы, но не входит в MVP (PLAN.md п. 1) или отложено.

## Интерфейс (UI_SPEC.md)
- Бейджи ограничений 14px у геометрии эскиза и цвета полной определённости/переопределённости.
- Рёбра выбора 2.5px и пунктирные рёбра превью ИИ: экранные квады вместо LineList в рендере.
- Окно выбора рамкой (слева направо — целиком, справа налево — пересечение).
- Анимации камеры 300 мс, fade меню, жест marking menu (махнуть с зажатой ПКМ).
- Схлопывание групп toolbar на узком окне; сетка избранного в S-box — перетаскиванием.
- Slice в палитре эскиза; ViewCube: стрелки поворота на 90° и компас-кольцо.
- Табличные цифры (`tnum`): egui не поддерживает OpenType-фичи.

## ИИ
- Стрим ответа модели в панель Assistant (сейчас ответ целиком).
- Подсказка грамматикой per-command (anyOf со схемой каждой команды) для слабых моделей.
- Дообучение (LoRA) на логах `logs/ai` — фаза 8.
- Генерация заготовки add-in по описанию.

## Плагины (Plugin API 1.1)
- Экспорт `panel` (декларативные панели) и `on-event` (открыт/сохранён документ, выбор, regen).
- Кнопки в marking menu и контекстном меню; SVG-иконки плагинов.
- Сеть по разрешению; магазин add-ins; установка по ссылке на Git.

## Моделирование
- Окружности/дуги в полигонах плагинов без дискретизации (Segment2::Arc в WIT).
- Измерение минимального расстояния между произвольными гранями (сейчас точно — для
  параллельных плоскостей, иначе между центрами).
- Сечение произвольной плоскостью и заливка сечения в рендере.

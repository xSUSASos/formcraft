# ADR 0005 — Модель ассистента по умолчанию

- Статус: принято
- Дата: 2026-10-17

## Контекст

PLAN Фаза 5: модель по умолчанию выбирается по `ai-bench` среди кандидатов под объём VRAM
(< 10 ГБ: `qwen2.5-coder:7b`, `qwen3:8b`). Цель — ≥ 70 % валидных тел на простых деталях.

Условия замеров: Windows 11, 12 потоков, 15 ГБ ОЗУ, RTX 4050 6 ГБ — **Ollama 0.40.4 не видит
GPU**, всё на CPU (см. PROGRESS → «Требует человека»). Бенч: 50 кейсов
(`crates/ai/bench/cases.json`, 30 simple + 20 medium, у каждого эталонный план), метрики —
валидное тело / перестройка при +10 % ко всем параметрам / совпадение габаритов, объёма и
числа цилиндрических граней. Сырые отчёты — `docs/bench/*.json`.

## Результаты

| Модель | Режим вывода | valid | rebuilt | matched | simple valid | с/кейс (CPU) |
|---|---|---|---|---|---|---|
| qwen2.5-coder:7b, прогон 1 | JSON-схема (грамматика) | 68 % | 68 % | 42 % | 63 % | 161 |
| **qwen2.5-coder:7b**, после исправлений | JSON-схема | **82 %** | **82 %** | **44 %** | **80 %** | **111** |
| qwen3:8b | JSON-схема | 0 % | 0 % | 0 % | 0 % | 236 |
| qwen3:8b | свободный текст (мышление) | — | — | — | — | > 600 на ответ (таймаут) |

Между прогонами 1 и 2 исправлено в конвейере (по разбору отказов): JSON с хвостом,
`feature.edit` при сборке с нуля, выдуманные имена тел в `target`, план без тела не считался
ошибкой, история попыток раздувала промпт, лимит ответа 2048 → 1200 токенов.

qwen3:8b под грамматикой (Ollama `format` со схемой) вырождается: пробелы/табы и пустые
`params: {}`. Это известное поведение «думающих» моделей при декодировании с грамматикой —
шаблон ждёт сначала блок `<think>`. Без грамматики модель думает свободно, но на CPU ответ
(до 4096 токенов) идёт дольше 10 минут — непригодно для интерактивной работы.

## Решение

- **По умолчанию `qwen2.5-coder:7b`** с декодированием по JSON-схеме плана (`AiConfig::default`).
  Цель «≥ 70 % валидных на простых» выполнена: 80 % на CPU.
- Для «думающих» моделей (`qwen3*`, `deepseek-r1*`) конфигурация сама выключает грамматику и
  даёт 4096 токенов (`AiConfig::from_env`); переопределяется `FORMCRAFT_AI_STRUCTURED`,
  `FORMCRAFT_AI_MAX_TOKENS` или в настройках. Пересмотреть qwen3:8b, когда Ollama увидит GPU.
- Время: на CPU 1–2 минуты на деталь; требование PLAN «< 60 с» относится к GPU с 12 ГБ VRAM и
  на этой машине не проверяемо до исправления детекции GPU.

## Последствия

- Совпадение с эталоном (44 %) — главный резерв: модель часто строит валидное, но не то тело
  (пропущенные отверстия, перепутанная высота). Следующие шаги — больше few-shot по классам
  ошибок, проверка «все размеры из запроса есть в параметрах», грамматика per-command
  (`docs/ideas.md`).
- `cargo xtask ai-bench` повторяет замер для любой модели (`FORMCRAFT_AI_MODEL=...`).

# ADR 0002 — Лицензии зависимостей

- Статус: принято
- Дата: 2026-10-15

## Контекст

PLAN.md: новые зависимости только MIT / Apache-2.0 / BSD; LGPL — только для ядра. Проверка —
`cargo deny` в `cargo xtask ci` (`deny.toml`).

## Решение

Разрешены лицензии кода: MIT, MIT-0, Apache-2.0 (в т.ч. WITH LLVM-exception), BSD-2/3-Clause, а
также пермиссивные лицензии того же класса, которые встречаются в базовых крейтах Rust-экосистемы:
ISC, Zlib, BSL-1.0, Unicode-3.0 (таблицы Unicode), CC0-1.0.

Исключения, ограниченные одним крейтом:

| Крейт | Лицензия | Почему |
|---|---|---|
| `occt-sys` | LGPL-2.1 | сборка OpenCascade, ядро (ADR 0001) |
| `epaint_default_fonts` | OFL-1.1, Ubuntu Font Licence 1.0 | шрифты интерфейса egui; это лицензии шрифтов, а не кода, свободно распространяются вместе с программой |

Любое новое исключение — только новым ADR. `cargo deny` также запрещает wildcard-версии и
неизвестные реестры/git-источники; внутренние крейты помечены `publish = false` (кроме
`formcraft-plugin-api`, который будет опубликован для авторов плагинов).

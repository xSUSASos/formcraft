# ADR 0004 — Внешний вид по UI_SPEC.md

- Статус: принято
- Дата: 2026-10-16

## Контекст

Пользователь добавил `UI_SPEC.md` — спецификацию внешнего вида в стиле Fusion 360 (цвета,
размеры, типографика, иконки, вид каждой зоны, приёмка скриншотами). Фазы 1–3 уже закрыты
с интерфейсом, который совпадает по раскладке, но расходится по виду (см. PROGRESS.md →
«UI: расхождения со спецификацией»).

## Решение

1. **`UI_SPEC.md` — источник правды по внешнему виду**, PLAN.md п. 2 ссылается на него;
   PLAN остаётся источником правды по раскладке и функциям.
2. **Единый модуль токенов** `crates/ui-egui/src/theme.rs`: цвета (§2, имена как в
   спецификации: `appbar_bg`, `toolbar_hover`, `panel_bg`, `selected_3d`, `sketch_profile`…) и
   размеры (§3, §5: `SIZE.appbar_h`, `SIZE.icon_toolbar`, `SIZE.dialog_w`…). Виджеты не содержат
   литеральных цветов и размеров. Светлая тема — по умолчанию.
3. **Шрифт Inter** (SIL OFL 1.1) встроен в бинарник (`crates/ui-egui/assets/fonts`, лицензия
   рядом), шрифты egui — запасные для символов. OFL допускается для шрифтов (как уже для
   `epaint_default_fonts`, ADR 0002). Табличные цифры (`tnum`) egui не поддерживает — известное
   ограничение.
4. **Иконки** — свои, рисуются в коде (`icons.rs`) по ТЗ `docs/icons.md` (двухцветные: контур
   `icon_outline` + акцент по смыслу). Рисование по ТЗ делегируется Sonnet, ревью — основной
   моделью.
5. **Приёмка внешнего вида**: `formcraft-cli screenshot <scene|all> <out>` рендерит сцены §8
   без окна (egui_kittest + wgpu, тот же 3D-вьюпорт, что в приложении), тест
   `every_spec_scene_renders` гоняет все сцены в CI. Приёмка любой фазы с UI включает снимки
   обеих тем и применимые пункты чек-листа §8; копии — `docs/images/ui/`.
6. **Закрытые фазы не переоткрываются**: исправления вида — отдельная задача
   «UI-выравнивание» (шаги в PROGRESS.md), меняется только внешний вид и раскладка, все
   существующие тесты остаются зелёными. Будущие зоны (Assistant, Scripts and Add-Ins,
   Inspect, тосты) делаются сразу по спецификации.

## Последствия

- Интерактивные тесты, завязанные на координаты, могут потребовать обновления при смене
  раскладки (канвас на всё окно, плавающий Browser) — логика при этом не меняется.
- egui_kittest стал обычной зависимостью `ui-egui` (фичи `wgpu`, `eframe`) ради скриншотов.
- Толстые рёбра выбора (2.5px) требуют экранных квадов в рендере — сделать в шаге 4.

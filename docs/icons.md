# Иконки FormCraft — ТЗ (UI_SPEC.md §4)

Все иконки свои, рисуются кодом в `crates/ui-egui/src/icons.rs` (egui `Painter`), без файлов-картинок.
Не трассировать и не копировать иконки Fusion/Autodesk. Цвета — только из токенов `theme.rs`.

## Стиль
- Плоский, **двухцветный**: контур `t.icon_outline` (#4A5056; в тёмной теме #C4CAD0) + **один цветной акцент**:
  - создание и изменение тел (Solid → Create/Modify) — `t.icon_create` (синий #1A8BD8);
  - эскиз и всё в эскизе — `t.icon_sketch` (оранжевый #E07B39);
  - конструктивная геометрия (плоскости, оси, Origin) — `t.icon_construct` (зелёный #2E9E5B);
  - ИИ — `t.ai` (фиолетовый #8A5CF6);
  - служебные (навигация, таймлайн, глаз, закрыть, меню) — только контур, без акцента.
- 3D-операции — лёгкая изометрия (кубик, цилиндр); акцент показывает **суть** операции:
  выдавленная грань, стрелка, скруглённое ребро, отверстие.
- Заливки граней — акцент или контур с прозрачностью 15–25% (`gamma_multiply`), не сплошные.
- Толщина линии: `(размер / 16).clamp(1.0, 2.0)` px; на 32px — 2px, на 16px — 1px. Скругления углов 1–2px.
- Поле иконки — квадрат; рисунок занимает центральные ~80% (отступ ≈ 10% с каждой стороны).
- Должна читаться на 16px: на маленьком размере можно опускать мелкие детали (параметр `r.width() < 20`).

## Размеры (токены `SIZE`)
toolbar 32px (`icon_toolbar`, с подписью под иконкой), выпадающие меню 16px (`icon_menu`),
Browser 16px (`icon_tree`), таймлайн 24px (`icon_timeline`), navigation bar 20px (`icon_nav`).

## Состояния
`IconState::{Normal, Hover, Pressed, Disabled}`:
- Normal — контур + акцент как выше;
- Hover — те же цвета (подложку рисует кнопка: `t.toolbar_hover`);
- Pressed — те же цвета (подложка `t.toolbar_pressed`);
- Disabled — всё (контур и акцент) серым `t.text_disabled` с непрозрачностью 40%.

## API (не менять сигнатуры существующих функций)
```rust
pub enum IconState { Normal, Hover, Pressed, Disabled }
pub fn paint_state(p: &Painter, r: Rect, id: &str, state: IconState, t: &Tokens);
/// Старый вход: `color` — цвет контура (вызовы по всему UI), акцент — по категории id.
pub fn paint(p: &Painter, r: Rect, id: &str, color: Color32, t: &Tokens);
pub fn accent_of(id: &str, t: &Tokens) -> Option<Color32>; // None для служебных
```
Неизвестный id — скруглённый квадрат с первой буквой (иконки плагинов не ломают UI).

|---|---|---|

| `line` | эскиз | отрезок по диагонали, оранжевые точки на концах |
| `rectangle` | эскиз | прямоугольник, оранжевые точки в углах |
| `circle` | эскиз | окружность, оранжевая точка в центре |
| `arc` | эскиз | дуга через 3 точки, точки оранжевые |
| `dimension` | эскиз | горизонтальная размерная линия со стрелками-засечками и выносными, оранжевая стрелка |
| `finish` | эскиз | круг с галочкой; круг заливка `t.ok`, галочка белая (единственное исключение по цвету) |
| `c_coincident` `c_horizontal` `c_vertical` `c_parallel` `c_perpendicular` `c_tangent` `c_equal` `c_concentric` `c_midpoint` `c_fix` `c_point_on_curve` | эскиз | значки ограничений, монохромный контур + оранжевая деталь (точка, буква H/V, «=», замок для fix) |

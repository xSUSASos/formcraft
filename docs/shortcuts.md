# Горячие клавиши и мышь

Список собран из кода: `crates/engine/src/*.rs` (`CommandSpec::shortcut`), `crates/ui-egui/src/app.rs`,
`sketch_mode.rs`, `menus.rs`, `viewcube.rs`. Клавиши без модификаторов работают, только когда фокус
не в текстовом поле (иначе клавиши уходят в поле).

> Горячие клавиши команд берутся из реестра команд (`CommandSpec::shortcut`), а не из таблицы в UI.
> Поэтому команда плагина может объявить свою клавишу, и она заработает без правок интерфейса.
> Переназначение клавиш планируется через настройки (Фаза 7).

## Навигация

| Действие | Как |
|---|---|
| Приближение и отдаление | Колесо мыши (масштаб к точке под курсором) |
| Сдвиг (pan) | Перетаскивание средней кнопкой |
| Вращение (orbit) | Shift + перетаскивание средней кнопкой |
| Вписать модель в окно (fit) | Двойной щелчок средней кнопкой или `F6` |
| Вид Home | `Home` или кнопка «домик» у ViewCube |
| Стандартный вид | Щелчок по грани, ребру или углу ViewCube (26 видов) |
| Левая кнопка на холсте | Режим выбирается на панели навигации: Orbit, Pan, Zoom или Select |

## Команды

| Клавиша | Команда | Название |
|---|---|---|
| `E` | `solid.extrude` | Extrude |
| `F` | `solid.fillet` | Fillet |
| `H` | `solid.hole` | Hole |
| `Q` | `solid.press_pull` | Press Pull |
| `Ctrl+Z` | `doc.undo` | Undo |
| `Ctrl+Y` | `doc.redo` | Redo |
| `Ctrl+Shift+Z` | `doc.redo` | Redo (запасная клавиша, задана в `app.rs`) |
| `Ctrl+S` | `doc.save` | Save |
| `Ctrl+O` | `doc.open` | Open |
| `S` | (интерфейс) | Окно быстрого поиска команд (Shortcut box) |

В диалоге фичи: `Enter` нажимает OK, `Esc` нажимает Cancel.

## Эскиз

Клавиши активны в режиме эскиза (после Create Sketch и выбора плоскости).

| Клавиша или действие | Что делает |
|---|---|
| `L` | Инструмент Line |
| `R` | Инструмент Rectangle |
| `C` | Инструмент Circle |
| `D` | Инструмент Dimension (щёлкнуть по объекту, ввести значение или выражение, `Enter`) |
| `Esc` | Сбросить незавершённую операцию; если её нет, вернуться к инструменту Select |
| Правая кнопка | Завершить цепочку линий (сбросить ожидающие точки); вне операции открывает маркирующее меню |
| `Delete` | Удалить выбранные объекты |
| Щелчок (Select) | Выбрать точку или кривую |
| `Ctrl` или `Shift` + щелчок | Добавить в выбор или убрать из выбора |
| Перетаскивание точки (Select) | Двигает точку; ограничения пересчитываются при отпускании кнопки |
| Кнопка Finish Sketch | Выйти из режима эскиза |

Инструмент 3-Point Arc выбирается кнопкой на панели, отдельной клавиши у него нет.

## Меню и поиск

| Действие | Что делает |
|---|---|
| Правая кнопка на холсте | Маркирующее меню: радиальные слоты (`repeat`, `solid.press_pull`, `solid.extrude`, `solid.hole`, `solid.fillet`, `sketch.create`, `doc.undo`, `ai.modify`) и список под ними (`solid.chamfer`, `solid.shell`, `solid.combine`, `doc.parameters`, `model.inspect`, `doc.redo`, `ai.generate`); незарегистрированные команды пропускаются |
| `Esc` или щелчок мимо меню | Закрыть маркирующее меню |
| `S` | Окно поиска команды: набрать часть названия, выбрать строку мышью или `Enter` |
| `Esc` в окне поиска | Закрыть окно |
| Двойной щелчок по фиче на таймлайне | Редактировать фичу |
| Правая кнопка по фиче на таймлайне | Меню фичи |
| Перетаскивание фичи или маркера на таймлайне | Изменить порядок или откатить модель |
